# Ecowatt Site (image variant)

- Reemplaza el video en **public/video/hero.mp4** (máx ~30–40 MB recomendado, H.264/AAC).
- Reemplaza el logo en **public/logo/logo-ecowatt.png** (PNG transparente).
- Para partners podés actualizar archivos en **public/partners**.

## Ejecutar local
```bash
npm i
npm run dev
```

## Build
```bash
npm run build
```
